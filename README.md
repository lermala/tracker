# Tracker

Веб-приложение для управления задачами и учета времени, затраченного на их выполнение.

> 🚧 Проект находится в процессе разработки.

**Демо:** https://lermala.github.io/tracker/

## Возможности

### Управление задачами

Можно создавать задачи, отмечать их выполненными и учитывать время, затраченное на работу.

<img width="800" alt="image" src="https://github.com/user-attachments/assets/a06ac671-63fe-49a3-9d87-d3fffe8a55c9" />


### Группировка задач

Задачи можно распределять по собственным разделам (колонкам), чтобы организовать рабочее пространство под себя.

## Статус проекта

Tracker активно разрабатывается. Функциональность и интерфейс будут постепенно дополняться.
