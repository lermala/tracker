# Tracker

Трекер задач и рабочего времени: проекты, разделы, список, доска и календарь.
> 🚧 Проект находится в процессе разработки.

[Открыть приложение](https://lermala.github.io/tracker/)

- Задачи со сроками, приоритетами, исполнителями и форматированным описанием.
- Таймер и отчёт по затраченному времени.
- Светлая и тёмная темы, настройка акцентного цвета.

## Запуск

```sh
npm install
npm run dev
```

Стек: JavaScript, SCSS, Vite и Supabase. Настройки подключения — в `js/supabaseClient.js`, SQL-схема — в `supabase/`.
